# Methodology Rules

## 1. Start from the research question

Do not choose a model first.

Use:

Research Question
→ Identification Problem
→ Data Structure
→ Candidate Methods
→ Method Selection

---

## 2. Causality

Before using causal language, assess:

- reverse causality
- omitted variables
- selection bias
- measurement error
- simultaneity

---

## 3. Robustness

Where appropriate consider:

- alternative variable definitions
- alternative samples
- lagged variables
- placebo tests
- alternative models
- instrumental variables
- propensity score methods
- fixed effects
- event studies

Do not add robustness tests mechanically.

Each test should address a specific concern.
