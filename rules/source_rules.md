# Source Rules

## 1. Source hierarchy

Prefer:

1. Original dataset
2. Government source
3. International organization
4. Official institutional report
5. Peer-reviewed academic paper
6. Professional organization
7. Professional media
8. Secondary aggregation
9. Blog / forum / self-media

---

## 2. Primary source requirement

For quantitative claims, attempt to locate the original source.

Example:

Bad:

A blog says China's GDP was X.

Better:

National Bureau of Statistics reports X.

---

## 3. Source verification

Every important source should record:

- Source ID
- Organization
- Title
- URL
- Publication date
- Data year
- Page/table
- Definition
- Unit
- Reliability
- Verification status

---

## 4. Source conflict

If two sources disagree:

Do not silently choose one.

Report:

Source A:
value X

Source B:
value Y

Possible reasons:

- different definitions
- different base year
- different statistical methodology
- different publication date
- revised data
- different geographic coverage
