# Data Rules

Before using a dataset, verify:

1. Variable definition
2. Unit
3. Time period
4. Frequency
5. Geographic coverage
6. Sample coverage
7. Price basis
8. Base year
9. Missing values
10. Revisions
11. Transformation
12. Source

---

## Variable consistency

Do not merge variables with different definitions
without explicitly documenting the transformation.

---

## Data provenance

Every constructed variable should record:

Original variable
Source
Transformation
Formula
Time period
Unit
Missing-value treatment
